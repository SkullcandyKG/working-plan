### 🔄 Непрерывные операционные процессы

* 🔵 **Контроль посещаемости** — Ежедневный мониторинг и выгрузка аналитики *(Старт с 28.08.2026)*.
* 🟡 **Рейтинг ППС** — Сбор индикаторов профессорско-преподавательского состава по кафедрам.
* 🟡 **Постмониторинг НААР** — Подготовка чек-листов по направлениям «Институциональный аудит» и «Ветеринария».
* 🟢 **Обучение КПК** — Проверка базы сертификатов «Педагогика и психология высшей школы» у новых ППС.
* 🔵 **Антиплагиат** — Администрирование корпоративных учетных записей и регулярная проверка работ.
* 🔵 **Лицензирование** — Плановый контроль соответствия материально-технической базы нормативам.
* 🟡 **Анкетирование** — Обновление опросников для замера удовлетворенности и аудит «Ящика доверия».
* 🟢 **Микроквалификация** — Разработка коротких образовательных треков и интеграция их в планы.
